# 联系我们

如果你在使用 Chaldea 时遇到问题、需要账号协助，或希望提出建议、隐私投诉及个人信息权利请求，可以通过以下渠道联系我们。

## 邮件联系

邮箱：[support@chaldea.center](mailto:support@chaldea.center)

账号问题、隐私投诉及涉及个人资料的请求，建议通过邮件联系。请勿在公开问题单或社区中发布密码、Token、验证码等敏感信息。

## 隐私问题与权利请求 {#privacy-contact}

如需查阅、复制、更正、补充或删除个人信息、撤回同意、注销账号，或对个人信息处理提出异议，请通过[邮件](mailto:support@chaldea.center)联系我们。相关处理规则见[隐私政策](./privacy)。

为便于处理，请说明：

- 请求类型，以及需要我们协助的具体事项。
- 如请求与账号有关，可提供用户名等定位所需信息；我们仅在核实请求所必要的范围内进一步确认身份。

隐私请求不默认要求你提供日志、截图或完整用户数据；请勿发送密码、Token 或验证码。

我们将在收到隐私投诉或权利请求后 **15 个工作日内答复**；无法直接办理的，将说明原因与可行途径。该答复时限适用于隐私事项。

## 问题与建议

- **应用内反馈**：通过“设置 → 反馈”提交技术问题或建议。应用内反馈会附带诊断日志和用户数据文件；隐私权利请求建议使用邮件渠道。
- **GitHub Issues**：在 [Chaldea Issues](https://github.com/chaldea-center/chaldea/issues) 报告可公开讨论的问题或功能建议。提交前可先搜索已有问题，避免重复。

GitHub Issues 是公开平台。公开提交截图或日志前，请移除账号资料及其他敏感信息；无需在公开问题单中留下个人邮箱。

## 社区交流

- [Discord 社区](https://discord.gg/5M6w5faqjP)
- [NGA FGO 社区主题](https://bbs.nga.cn/read.php?tid=24926789)

社区适合一般讨论和经验交流。账号资料、隐私投诉及个人信息权利请求请通过邮件联系。

## 反馈信息准备

报告技术问题时，尽量提供以下信息：

- App 版本、数据版本、设备型号及系统版本。
- 出现问题的页面、复现步骤、预期结果和实际结果。
- 与问题有关、已移除敏感信息的截图或日志（如有）。

提出功能建议时，请说明使用场景、目前遇到的困难及期望行为。通过邮件或应用内反馈提交后，如希望收到回复，请提供可用的联系方式。
